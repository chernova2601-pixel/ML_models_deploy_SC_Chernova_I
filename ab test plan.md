# План A/B-теста

## Разделение трафика
50/50 по user_id (случайное распределение).

## Продолжительность
2 недели или до 10 000 событий в группе.

## Метрики
- Основная: F1-score (класс дефолта).
- Дополнительная: Recall (важно не пропускать дефолты).

## Статистический анализ
t-test для средних, доверительные интервалы – бутстрап.

## Реализация в сервисе
API может принимать заголовок `X-Model-Version` или использовать отдельные эндпоинты `/predict/v1`, `/predict/v2`.
